# NextGen Studio - Digital Business Card

Interactive, responsive digital business card with glassmorphism design for **NextGen Studio (Rao Sabir Ali)**.

## ✨ Features
- **Design:** Modern 3D frosted glassmorphism effect with glowing bokeh particles.
- **Brand Typography:** Styled with the geometric `Outfit` font matching official NextGen Studio branding.
- **Active Social Links:**
  - Facebook: [Rao Sabir Ali](https://www.facebook.com/rao.sabir.ali.2025?mibextid=ZbWKwL)
  - Instagram: [@sabir_ali_rao](https://www.instagram.com/sabir_ali_rao?stkn=MWRxcGYyYTcyN2g4dA==)
  - YouTube: [@heathysecret](https://youtube.com/@heathysecret?si=EnPG0prVcz52uG_B)
  - LinkedIn: [Anusha Sabir](https://www.linkedin.com/in/anushasabir?utm_source=share_via&utm_content=profile&utm_medium=member_android)
- **Direct Contacts:** One-click WhatsApp, Phone Call, Email, and Google Maps Location.
- **Interactive QR Code:** Glowing dual-gradient neon border with center brand logo.
- **Fully Responsive:** Smoothly adapts across all mobile devices, tablets, and desktops.

## 🚀 How to Run Locally
Simply open `index.html` in any modern web browser, or run the local server:
```bash
node server.js
```
Then visit `http://localhost:3000` (or `5500`).
